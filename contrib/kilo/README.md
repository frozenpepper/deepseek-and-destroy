# Kilo compatibility location

Kilo Code is a first-class DSD harness in this release. Canonical documentation and
assets moved to:

- `../../KILO.md`
- `../../adapters/kilo/README.md` and `../../adapters/kilo/` assets
- `../../scripts/install_kilo_workers.py`
- `../../scripts/install_harness_adapter.py --harness kilo`

The two Python files in this directory are compatibility wrappers for older DSD
commands. They contain no independent Kilo implementation.
